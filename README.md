# 一寸先は嘘

挑戦者は部屋を抜けていく。各部屋には選択肢があり、正解は一つ。
**正解がどれかは、助言者だけに見えている。**
助言者はヒントを送るが、一部は嘘つきに配役されている。

> 答えを知っているのは、君以外の全員だ。

### 設計は三度作り直している

1. 全員が正解を知る形 → **多数決で解けた**（全構成で生存率100%）
2. 助言を伏せて数通だけひらく形 → **運ゲーになった**（ひらく時点で判断材料が無い）
3. **協力者に正解を教えない形** ← いま

当てずっぽうでは1部屋あたり19.2%しか生き残れず、名の数を数えるだけで62.0%、
迷いの言葉と記録まで読むと69.9%（通常モード）。
基準にしている「腕の差」は 12.7pt（通常）／22.1pt（崖っぷち）／39.5pt（全員挑戦者）。
**測り方が打ち手の組み合わせごとに違う**ので、数字の出どころは
`docs/RUBRIC.md` を見てほしい。経緯は `docs/BALANCE.md`。

## 遊び方

### 誰が何を知っているか

| | 正解を | 何が見えるか |
|---|---|---|
| 挑戦者 | 知らない | 選択肢と、届いた助言 |
| **嘘つき**（半数） | **知っている** | 正解と、**罠**。罠は嘘つき全員に共通 |
| 協力者・目利き | 知らない | 「このどちらかが生きる」 |
| 協力者・半可通 | 知らない | 「この三つのどれか」 |
| 協力者・耳打ち | 知らない | 「これは死ぬ」を一つだけ |

要点は二つ。

**協力者は正解を知らないので名指しできない。** だから多数決では解けない。
断言できるのは嘘つきだけになる。

**嘘つきは全員が同じ罠を見ている。** だから嘘が1点に集まり、
罠が正解を票数で上回る部屋が生まれる。
**一番票が集まった選択肢の的中率は85%** ——群れに従うと15%の確率で死ぬ。

嘘つきは毎回は嘘をつかない。信用を作ってから裏切れる。
誰が嘘つきかは区画（4〜5部屋）のあいだ変わらないので、記録が手掛かりになる。

### 1部屋の流れ

1. 部屋と選択肢が出る
2. 発言枠の助言者が20文字の助言を送る。**全員ぶん、名前つきで挑戦者に見える**
3. 助言者は**互いを指せる**（「あいつは嘘だ」）。扉について言う口とは別なので、
   指しても自分の一言は消えない。一部屋につき口は二つ
4. 発言枠の外にいる人（配信なら大多数）は**一票だけ賭けられる**。
   当たり外れの通算と順位が本人に返り、当てているほど次の区画で発言枠に上がりやすい
   （手を挙げた人は×4、賭けを当てている人は最大×2。逆に、席にいて一言も
   書かなかった人は次の区画で×0.15＝席が喋る人に回る）
5. 挑戦者は誰か1人を「黙らせる」ことができる（崖っぷちのみ。当たれば以降その人の声は届かない）
6. 挑戦者は助言の行に**疑いの札**を置ける。**札は相手に伝わる**——
   置かれた本人の画面には「あなたは疑われている」が出て、その人は次の一言を
   **扉ひとつの言い切り**にしなければならない（迷いの言い方は通らない。人間もAIも同じ規則）。
   言い切らせれば次の部屋で正誤が付く＝記録が早く固まるが、その人の迷いは読めなくなり、
   嘘つきは札の付いた者へ寄って埋めにかかる。外した札は代金を払う
   （全員挑戦者モードだけは、挑戦者が何人もいるので配らない）
7. 1つ選ぶ（60秒）
8. 生死が確定する
9. 書いた本人へ結果が返る——「あなたの言葉で通った」「あなたの言葉で死んだ」
   「信じられなかった。挑戦者は死んだ」。賭けた人には当たり外れと順位

### 区画の終わりに

区画を離れるとき（抜けた、あるいは二部屋以上進んで落ちた）、
**誰が嘘つきだったかが開く。** 挑戦者が見ていた記録を横に並べるので、
「正4 嘘0 なのに嘘つき」——信用を積んでから裏切った者が数字のほうから見える。
置いた疑いの札と突き合わせて、読みに点が付く。
点は一周ぶんも積んで、終わりの画面に出る
（「嘘つき12人のうち8人を疑っていた／正直な3人を疑った」）。

顔ぶれと配役は区画をまたいで残らない（抜けても落ちても引き直す）ので、
ここで開いても先の部屋には何も漏れない。同じ紙は助言者にも配る。

一周終わったあとは、**同じ賭場のまま次の周へ入れる。**
見ていた全員に毎周合言葉を入れ直させない。

配役は**区画（4〜5部屋）のあいだ固定**。だから
「ずっと本当のことを言って信用を作り、ここぞで裏切る」が起こる。
区画が変わると顔ぶれごと入れ替わる。

### 助言の決まり

- 20文字まで
- **番号と位置では指せない**（「3番」「左から2番目」）。
  数えられる指し方を許すと多数決に戻り、一度の助言で全選択肢を潰せてしまう
- **一度に触れてよい選択肢は2つまで**

  advisor-gateway.ts 助言者の供給源。人間 / AI / なし を差し替える境界
  ai-advisors.ts    AI の助言者。ソロで人間の代わりに入る

### 設計上、崩してはいけない点

- **正解は挑戦者クライアントに渡らない。** `PublicRoom` 型が `correct` を持たないので、
  ネットワーク越しでも答えが挑戦者側へ流れる経路が型で塞がれている
- **助言者ページは配信映像に依存しない。** 盤面はサーバーから直接受け取る
- **人間かAIかで分岐しない。** `AdvisorGateway` の先を本体は知らない
- **助言者ページに zod もアニメーションライブラリも載せない。** 初速が命
- 部屋データは JSON。将来のプレイヤー投稿も同じ入口を通す
- **助言は伏せない。** 一時期「ひらける数」を絞っていたが、
  ひらく時点で判断材料が無く運ゲーになった。読ませるものは全部見せて、
  嘘を混ぜるほうで難しくする。根拠は `docs/BALANCE.md`
- **配役が開くのは二か所だけ。** 区画を離れるときの `section/answer` と、
  一周の終わりの `game/over`。遊んでいるあいだの便には載せない
  （判定に載っていた時期があり、一部屋抜けるたびに区画ぶんの配役が
  挑戦者の線へ流れていた。`tools/answer-check.mjs` が毎回見る）
- **疑いの札は公開する。** 撃たれる側が振る舞いを変えられるので、
  入れる前に測った（`tools/doubt-probe.mjs`）。「撃たれている者ほど本当のことを
  言っている」は倍率6まで向きも強さも保ち、外した札のほうに代金が付いた
  （協力者に置いた札の持ち主が撃たれる回数 0.26 → 0.66）
- **押された者は言い切る。** 札を置かれた者は扉ひとつを名指しするしかない。
  記録が早く固まる代わりに、その人の迷いは読めなくなる
  （`tools/press-probe.mjs`。均衡は `PRESS=2 node tools/rubric.mjs` で 7/7）
- **常連は残る。** AI の顔ぶれは周をまたいで同じ12人（振る舞いは毎周引き直す）。
  区画の答え合わせで開いた配役を積んで、助言の行に「裏切2/5」が出る。
  いまの役ではないが飾りでもない——嘘つきの引きは人ごとに重みが違うので、
  よく裏切る常連は本当によく裏切る（通常で +2.2pt、崖っぷちでは逆に損。
  `tools/rubric.mjs` の「常連の癖を知っている」で測る）

## 費用

**段階4（通信）も無料で始められる。** 以前ここに「有料プラン $5/月が必須」と
書いていたが、SQLite バックエンドの Durable Objects は2025年4月から
Workers 無料プランで使える。前提が古かった。

| 項目 | 費用 |
|---|---|
| Cloudflare Workers 無料プラン | **¥0** |
| 独自ドメイン | 要らない（`*.workers.dev` で検証できる） |
| Workers 有料 $5/月 | 無料枠（13,000 GB-s/日）を超えてから |
| Sentry | 無料枠 |

無料枠は1周15分として**1日115周**（オブジェクトを眠らせない素朴な実装の場合）。
WebSocket Hibernation を使えば桁が変わる。**そのため
「Hibernation を使う・締切は alarm で持つ」は最適化ではなく設計条件。**
根拠と計算は `docs/COST.md`。

## 収益（フェーズ1では稼がない）

- 挑戦者画面に広告を出さない（配信に映るため）
- 広告は助言者ページの**結果画面のみ**。本体描画後に遅延ロードする
- 目的は検証と KoshinStudio への送客
