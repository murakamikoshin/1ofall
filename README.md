# 一寸先は嘘

挑戦者は部屋を抜けていく。各部屋には選択肢があり、正解は一つ。
**正解がどれかは、助言者だけに見えている。**
助言者はヒントを送るが、一部は嘘つきに配役されている。

> 答えを知っているのは、君以外の全員だ。

## 今どこまで動くか

実装順序（仕様書 §12）に対する現在地。

| # | 段階 | 状態 |
|---|---|---|
| 1 | 画像スタイルの確定 | **規約は確定・10枚テストは未実施**（`docs/IMAGE_STYLE.md`） |
| 2 | ローカル1人プレイ・死亡演出 | **動く** |
| 3 | 手触りの確認 | ← **いまここ。ここで面白くなければ先に進まない** |
| 4 | ルーム作成 + 助言者入室（PartyKit） | 未着手（画面のみ先行、接続は差し込み口を用意済み） |
| 5〜10 | 発言枠・嘘つき・残機・荒らし対策・部屋増量 | ロジックは実装済み、通信待ち |

## 動かす

```bash
npm install
npm run dev          # http://localhost:5173        挑戦者
                     # http://localhost:5173/advisor.html  助言者（スマホ幅で見る）
```

```bash
npm run build            # 型検査 + 本番ビルド
npm run validate:rooms   # 部屋データの検証
npm run images:manifest  # 生成が必要な画像の一覧
npm run gen:sfx          # 効果音を作り直す
npm run shots <dir>      # Playwright で全画面スクショ
```

## 構成

```
index.html          挑戦者（将来 Tauri で包んで Steam 版本体にする）
advisor.html        助言者（無料ブラウザ・永続。Webフォントを読まない）

src/core/           通信も DOM も知らない純粋ロジック
  schema.ts         Zod。部屋データと通信メッセージの唯一の正
  limits.ts         数値制約のみ。zod を持たない（助言者ページ用）
  engine.ts         状態機械。配信・友達内・ソロで同じものが動く
  casting.ts        発言枠と嘘つきの配役。人数で自動調整、分岐しない
  advisor-gateway.ts 助言者の供給源。人間 / AI / なし を差し替える境界
src/ui/             描画とそれ以外
  death-sequence.ts 死亡演出
  placeholder.ts    本番画像が来るまでの仮絵
data/rooms.core.json 部屋データ。コードから分離してある
```

### 設計上、崩してはいけない点

- **正解は挑戦者クライアントに渡らない。** `PublicRoom` 型が `correct` を持たないので、
  ネットワーク越しでも答えが挑戦者側へ流れる経路が型で塞がれている
- **助言者ページは配信映像に依存しない。** 盤面はサーバーから直接受け取る
- **人間かAIかで分岐しない。** `AdvisorGateway` の先を本体は知らない
- **助言者ページに zod もアニメーションライブラリも載せない。** 初速が命
- 部屋データは JSON。将来のプレイヤー投稿も同じ入口を通す

## 費用（着手前に確認が必要）

フェーズ1で通信を繋ぐと、以下が発生する。

| 項目 | 費用 |
|---|---|
| Cloudflare Workers 有料プラン（PartyKit / Durable Objects に必須） | **$5/月〜** |
| Durable Objects の従量課金（同時接続と実行時間に応じて） | 従量 |
| 独自ドメイン | 年 $10 前後 |
| Sentry | 無料枠 |

**現状のコード（実装順序 2 まで）は無料で動く。** 課金が要るのは段階4から。

## 収益（フェーズ1では稼がない）

- 挑戦者画面に広告を出さない（配信に映るため）
- 広告は助言者ページの**結果画面のみ**。本体描画後に遅延ロードする
- 目的は検証と KoshinStudio への送客
