# 一寸先は嘘

挑戦者は部屋を抜けていく。各部屋には選択肢があり、正解は一つ。
**正解がどれかは、助言者だけに見えている。**
助言者はヒントを送るが、一部は嘘つきに配役されている。

> 答えを知っているのは、君以外の全員だ。

### 設計は三度作り直している

1. 全員が正解を知る形 → **多数決で解けた**（全構成で生存率100%）
2. 助言を伏せて数通だけひらく形 → **運ゲーになった**（ひらく時点で判断材料が無い）
3. **協力者に正解を教えない形** ← いま

素朴な多数決では38.8%しか勝てず、迷いの言葉まで読むと82.9%。
**読みの差が44ポイント。** 経緯と数字は `docs/BALANCE.md`。

## 遊び方

### 誰が何を知っているか

| | 正解を | 何が見えるか |
|---|---|---|
| 挑戦者 | 知らない | 選択肢と、届いた助言 |
| **嘘つき**（半数） | **知っている** | 正解と、**罠**。罠は嘘つき全員に共通 |
| 協力者・目利き | 知らない | 「このどちらかが生きる」 |
| 協力者・半可通 | 知らない | 「この三つのどれか」 |
| 協力者・耳打ち | 知らない | 「これは死ぬ」を一つだけ |

要点は二つ。

**協力者は正解を知らないので名指しできない。** だから多数決では解けない。
断言できるのは嘘つきだけになる。

**嘘つきは全員が同じ罠を見ている。** だから嘘が1点に集まり、
罠が正解を票数で上回る部屋が生まれる。
**一番票が集まった選択肢の的中率は85%** ——群れに従うと15%の確率で死ぬ。

嘘つきは毎回は嘘をつかない。信用を作ってから裏切れる。
誰が嘘つきかは区画（6部屋）のあいだ変わらないので、記録が手掛かりになる。

### 1部屋の流れ

1. 部屋と選択肢が出る
2. 発言枠の助言者が20文字の助言を送る。**全員ぶん、名前つきで挑戦者に見える**
3. 挑戦者は誰か1人を「黙らせる」ことができる（当たれば以降その人の声は届かない）
4. 1つ選ぶ（60秒）
5. 生死が確定する

配役は**区画（6部屋）のあいだ固定**。だから
「ずっと本当のことを言って信用を作り、ここぞで裏切る」が起こる。
区画が変わると顔ぶれごと入れ替わる。

### 助言の決まり

- 20文字まで
- **番号と位置では指せない**（「3番」「左から2番目」）。
  数えられる指し方を許すと多数決に戻り、一度の助言で全選択肢を潰せてしまう
- **一度に触れてよい選択肢は2つまで**

## 構成

```
index.html          挑戦者（将来 Tauri で包んで Steam 版本体にする）
advisor.html        助言者（無料ブラウザ・永続。Webフォントを読まない）

src/core/           通信も DOM も知らない純粋ロジック
  schema.ts         Zod。部屋データと通信メッセージの唯一の正
  limits.ts         数値制約と1周の骨格。zod を持たない（助言者ページ用）
  engine.ts         状態機械。配信・友達内・ソロで同じものが動く
  casting.ts        発言枠と嘘つきの配役。人数で自動調整、分岐しない
  advisor-gateway.ts 助言者の供給源。人間 / AI / なし を差し替える境界
  ai-advisors.ts    AI の助言者。ソロで人間の代わりに入る
  hint-writer.ts    助言の文面を組み立てる
  moderation.ts     助言の検閲と通報。段階4のサーバーも同じ関数を通す
src/i18n/           文言。ja / en。部屋データも言語ごとに持つ
src/ui/             描画とそれ以外
  death-sequence.ts 死亡演出
  placeholder.ts    本番画像が来るまでの仮絵
data/rooms.core.json 部屋データ48室。コードから分離してある
```

### 設計上、崩してはいけない点

- **正解は挑戦者クライアントに渡らない。** `PublicRoom` 型が `correct` を持たないので、
  ネットワーク越しでも答えが挑戦者側へ流れる経路が型で塞がれている
- **助言者ページは配信映像に依存しない。** 盤面はサーバーから直接受け取る
- **人間かAIかで分岐しない。** `AdvisorGateway` の先を本体は知らない
- **助言者ページに zod もアニメーションライブラリも載せない。** 初速が命
- 部屋データは JSON。将来のプレイヤー投稿も同じ入口を通す
- **ひらける助言の数は `openLimit = 嘘つき数 × 2 − 1`。** これを緩めると
  全部見えていた頃と同じで、多数決で解ける。根拠は `docs/BALANCE.md`
