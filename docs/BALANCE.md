# ゲームバランスの根拠

数字はすべて `tools/` のシミュレーションと実プレイで出したもの。再現できる。

```bash
node tools/sim.mjs    # 全部見えると多数決で解けること
node tools/sim4.mjs   # 嘘つきの人数と示し合わせの影響（崖であること）
node tools/sim6.mjs   # 発言者数ごとの適正な開封数
node tools/sim7.mjs   # 配役を区画で固定すると解けてしまうこと
node tools/playtest-v2.mjs 6   # 実ビルドで通しプレイ
```

## 1. なぜ「ひらく数を絞る」のか

初版は全員の助言が挑戦者に見えていた。この形は**多数決で解ける**。

正直者は必ず過半を占めるので、一番多く名指しされた選択肢を選べば必ず正解する。
実測：**全構成で生存率100%**（友達4人でも配信1000人でも）。

嘘つきの人数を増やしても直らない。生存率は嘘つきの比率に対して崖になる。

| 発言枠5人 | ばらばらに嘘 | 示し合わせて嘘 |
|---|---|---|
| 嘘つき2人 | 100% | 100% |
| 嘘つき3人（過半） | 66% | 0% |
| 嘘つき4人（過半） | 2% | 0% |

過半に届かなければ必ず生き、過半に届けば必ず死ぬ。中間が無い。

**助言を伏せて届け、ひらける数を絞る**とこれが解ける。
ひらいた3通のうち2通が嘘なら致命傷になるので、嘘つきが全体の少数のままでも危険になる。

### ひらける数

**3通に固定**（ただし発言者数が少ないときは「全員より1人少ない」まで）。

最初は「嘘つき数 × 2 − 1」という式にしていたが、実物の助言文で測ったら合わなかった。
助言の3割は「○○はやめろ」という外し型で、押し型より情報量が少ないためで、
式どおりだと嘘つき1人の部屋が60%台まで落ちた。実測で決め直した。

| 開封 | 発言8人 | 発言6人 | 発言4人 |
|---|---|---|---|
| 1通 | 66.8% | 59.4% | 66.6% |
| 2通 | 72.8% | 64.5% | 72.7% |
| **3通** | **86.0%** | **78.2%** | **90.9%** |
| 4通 | 93.1% | 88.2% | 97.8% |
| 5通 | 97.5% | 95.4% | — |

3通は、嘘つき2人が開封の過半（2/3）を取れる最小の奇数でもある。
4通以上にすると90%を超えて緩み、2通以下だと情報が足りず運になる。

**全部は見えない、という原則は人数がどれだけ少なくても破らない。**
発言者3人なら2通まで。ここを緩めると、初版と同じで多数決に戻る。

### 嘘つきの人数は毎回1〜2人で揺れる

人数を固定すると、発言枠5人と6人のあいだで生存率が90%と78%に割れて段差が出る。
実際、助言者5人のときだけ1周10.7分・全踏破4%という異常な難度になっていた。

部屋ごとに1〜2人で揺らすと段差がならされ、
さらに「今回は何人いるのか分からない」という不確かさが乗る。
**挑戦者には正確な人数を知らせない**（「1〜2人」とだけ出す。
正確な数が分かると、1人と判明した時点でその部屋は安全になってしまう）。

| 助言者 | 前（固定） | 後（1〜2人で揺らす） |
|---|---|---|
| 5人 | 10.7分 / 全踏破 4% | **15.3分 / 28%** |
| 4人 | 17.8分 / 全踏破 83% | **11.9分 / 7%** |

## 2. 1周の長さ

初版は**1周18.4秒**だった。手掛かりが無く5択を当てずっぽうで引くだけなので、
命3が平均1.4部屋で尽きた。配信で回る長さではない。

配信向けゲームの相場から逆算した。

| ゲーム | 1ラウンド | 1周 |
|---|---|---|
| Among Us | 10〜15分 | 同左 |
| Jackbox系 | 2〜3分/問 | 15〜20分 |
| Fall Guys | 2〜3分/種目 | 10〜15分 |

視聴者参加型は「入ってすぐ関われる」ことが要るので**1部屋30〜60秒**は動かさない。
変えたのは**1周**で、10〜15分を狙う。

### 骨格

| 項目 | 値 |
|---|---|
| 1周 | 4区画 × 6部屋 = 24部屋 |
| 命 | 4 |
| 死んだとき | その区画の最初に戻る。部屋は引き直す |
| 制限時間 | 60秒（黙らせを外すと次の部屋が15秒短くなる） |

### 区画ごとの難度

発言枠を狭めると、ひらいた中に嘘つきが混じる率が上がる。これが難度スライダー。

| 区画 | 発言枠 | 開封 | 1部屋の生存率（実測） |
|---|---|---|---|
| 1 | 8人 | 3通 | 86% |
| 2 | 7人 | 3通 | 83% |
| 3 | 6人 | 3通 | 78% |
| 4 | 5人 | 3通 | 71% |

区画3〜4では6択以上の部屋を優先して出す。

### 1周の長さ（実物のロジックで20000周）

1部屋38秒として。腕前は「助言が割れたときに正解を見抜ける確率」。

| 助言者 | 腕前 | 挑戦部屋 | 全踏破 | 1周 |
|---|---|---|---|---|
| 12人 | 0% | 22.3 | 14% | **14.1分** |
| 12人 | 30% | 25.0 | 29% | **15.8分** |
| 12人 | 60% | 27.3 | 52% | **17.3分** |
| 7人 | 30% | 24.0 | 26% | 15.2分 |
| 5人 | 30% | 24.1 | 28% | 15.3分 |
| 4人 | 30% | 18.8 | 7% | 11.9分 |

腕前で全踏破率が14%→52%に動く。**読みが結果に効いている。**

## 3. 採らなかった案

### 区画のあいだ配役を固定する

記録に意味を持たせるために試したが、**1部屋目で嘘つきが割れて残りが100%になる**。
区画平均98%、全踏破96%。読み合いが1部屋で終わる。

| 配役の引き方 | 平均 | 区画内の推移 |
|---|---|---|
| 毎部屋 引き直し | 89.3% | 89% → 90% → 89% → 89% → 89% → 89% |
| 区画のあいだ固定 | 98.3% | 90% → 100% → 100% → 100% → 100% → 100% |

よって**毎部屋引き直し（元の仕様どおり）**を採る。

### 代わりに入れたもの：嘘の癖

毎部屋引き直すと、過去の記録が何も予測しない飾りになってしまう。
そこで一人ひとりに**嘘つきに選ばれやすさの癖**（0.35〜2.4倍、id から決まる）を持たせた。

- よく裏切る常連と、めったに裏切らない常連が自然に生まれる
- 記録は弱い手掛かりになるが、確実ではないので読み切れない
- 配信で「あいつはいつも嘘つく」という語りが生まれる

## 4. 実測（実ビルドでの通しプレイ）

素朴な打ち手（ひらけるだけひらいて多い方に賭ける）のボットで計測。
人間はここに読みが乗るので、これは**腕前の下限**にあたる。

- 1部屋あたりの生存率 74〜80%
- 1周の選択回数 15〜20回
- 同じ部屋を続けて見る回数 **0回**（初版は1.6回）

人間の思考時間（1部屋 35〜40秒）を入れると**1周 10〜13分**。

## 5. まだ確かめられていないこと

- **人間の嘘つきは示し合わせる可能性がある。** AI助言者は互いを知らないので
  嘘がばらけるが、人間は盤面を見て同じ外れに寄せるかもしれない。
  そうなると生存率は上表より下がる。人で試すまで分からない
- 助言の文面から嘘を見抜けるか（言い回しの癖）。これが読みの本体だが、
  シミュレーションでは測れない
- 1部屋あたりの実時間。ボットは思考しないので、35〜40秒という前提は仮置き
