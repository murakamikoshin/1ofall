# ゲームバランスの根拠

数字はすべて `tools/` で再現できる。

```bash
node tools/sim.mjs     # 全部見えて全員が正解を知ると多数決で解けること
node tools/sim4.mjs    # 嘘つきの人数を増やしても崖になるだけであること
node tools/sim12.mjs   # いまの形（協力者は二択までしか知らない）
node tools/sim13.mjs   # 区画ごとの難度と、配役を固定した場合
node tools/playtest-v2.mjs 5   # 実ビルドで通しプレイ
```

## 1. 三度作り直している。何が駄目だったか

### 一代目：全員が正解を知っていて、助言は全部見える

**多数決で解ける。** 正直者は必ず過半を占めるので、一番多く名指しされた選択肢を選べば必ず当たる。
実測で**全構成が生存率100%**（友達4人でも配信1000人でも）。

嘘つきの人数を増やしても直らない。生存率は崖になり、中間が無い。

| 発言枠5人 | ばらばらに嘘 | 示し合わせて嘘 |
|---|---|---|
| 嘘つき2人 | 100% | 100% |
| 嘘つき3人（過半） | 66% | 0% |
| 嘘つき4人（過半） | 2% | 0% |

### 二代目：助言を伏せ、3通だけひらかせる

**運ゲーになる。** 誰をひらくかを決める時点で判断材料が何も無く、
読みはひらいた後にしか働かない。勝敗を決める決断が無情報だった。

「記録を見て選べる」ようにもしたが、嘘つきを毎部屋引き直していたので
記録に予測価値が無く、飾りにしかなっていなかった。

### 三代目（いま）：協力者に正解を教えない

- **嘘つきは正解を正確に知っている**
- **協力者は「このどちらかが生きる」までしか知らない**（正解＋外れ1つ。人ごとに違う）
- **助言は全員ぶん、最初から全部見える**（伏せない）

これで三つ同時に解ける。

1. 協力者は正解を名指しできないので、票が割れて**多数決が決め手にならない**
2. 伏せないので**ひらく運ゲーが消える**
3. 正解は全協力者の候補に必ず入るので、**迷いの言葉まで読めば浮かび上がる**

そして**断言できるのは正解を知っている嘘つきだけ**になる。断言そのものが手掛かりになる。

実物の助言文で測った、読み方ごとの1部屋あたり生存率。

| 挑戦者の読み方 | 生存率 |
|---|---|
| 当てずっぽう | 19.0% |
| 断言を重く見る（素朴。設計と逆の読み） | 69.9% |
| 断言と迷いを区別しない | 75.3% |
| **迷いを重く見る（設計どおり）** | **81.7%** |

**「断言している者ほど疑う」と分かっているかどうかで12ポイント動く。**
協力者は正解を知らないので断言できない。断言できるのは嘘つきだけ。

## 2. 「ずっと本当を言って最後に裏切る」

配役は**区画のあいだ固定**する。顔ぶれも嘘つきも6部屋変わらない。

一代目の設計で配役を固定したときは1部屋目で嘘つきが割れ、
残りが100%になって壊れた（区画平均98.3%）。
いまの形では壊れない。**協力者自身が正解を知らず本当に迷っているので、嘘つきが迷ったふりに紛れられる。**

| 区画内の推移（発言6人・嘘つき2人） | |
|---|---|
| 78% → 81% → 82% → 83% → 83% → 84% | 信用が積まれて楽になっていく |

区画が変わると顔ぶれごと入れ替わり、積んだ読みは捨てられる。
区画の1部屋目がいちばん危ない、という山が6部屋ごとに来る。

嘘つきは毎部屋「押す」か「本当のことを言って信用を作る」かを選べる。
ここぞで裏切るには、それまで信用されている必要がある。

## 3. 1周の長さ

一代目は**1周18.4秒**だった。配信で回る長さではない。

配信向けゲームの相場から逆算した。

| ゲーム | 1ラウンド | 1周 |
|---|---|---|
| Among Us | 10〜15分 | 同左 |
| Jackbox系 | 2〜3分/問 | 15〜20分 |
| Fall Guys | 2〜3分/種目 | 10〜15分 |

視聴者参加型は「入ってすぐ関われる」ことが要るので**1部屋30〜60秒は動かさない**。
変えたのは1周だけ。

| 項目 | 値 |
|---|---|
| 1周 | 4区画 × 6部屋 = 24部屋 |
| 命 | 4 |
| 死んだとき | その区画の最初へ。部屋は引き直す |
| 制限時間 | 60秒（黙らせを外すと次が15秒短くなる） |

### 区画ごとの難度

| 区画 | 発言枠 | 協力者の絞り込み | 生存率（設計どおりの読みで） |
|---|---|---|---|
| 1 | 8人 | 二択 | 94% |
| 2 | 7人 | 二択 | 91% |
| 3 | 6人 | 二択 | 87% |
| 4 | **8人** | **三択** | **55〜64%** |

最終区画だけ発言枠が広がるのは、賭場中が見物に来るという理屈。
人数が増えるぶん協力者の絞り込みを三択に落として難度を上げている。
声は増えるのに、一つ一つが頼りなくなる。

助言者が少ない場合（友達モード）も同じ規則で自動調整される。
発言枠が4人以下では嘘つきは1人（2人だと正直者が足りない）。

### 1周の実測（実物のロジックで6000周）

| 読み方 | 挑戦部屋 | 全踏破 | 1周 |
|---|---|---|---|
| 素朴（断言を重く見る） | 20.8 | 1% | **13.2分** |
| 区別しない | 23.8 | 2% | 15.1分 |
| 設計どおり（迷いを重く見る） | 27.1 | **10%** | **17.2分** |

読みの腕で全踏破率が1%から10%に動く。運では抜けられない。

### 実ビルドでの通しプレイ（6周）

| | |
|---|---|
| 1周の選択回数 | 平均 **19.0回**（計算値 20.8〜27.1 の範囲内） |
| 1部屋あたりの生存率 | **79%**（計算値 81.7%） |
| 到達した部屋 | 平均 12.2 |
| 同じ部屋を続けて見た回数 | **0回** |

人間の思考時間（1部屋35〜40秒）を入れると**1周 11〜13分**。
計算と実物が一致しているので、以降の調整は `tools/sim14.mjs` で足りる。

## 4. 一度の助言で全選択肢に触れる攻撃

「1234は罠」のように、一度の助言で全部の選択肢を潰そうとする者が出る。
これは二つの規則で塞いである。

- **番号と位置で指す言い方を禁止する**（半角・全角・漢数字・丸数字・左右・真ん中・端・n番目）。
  数えられる指し方ができると、助言が機械的に集計できてしまい多数決に戻る
- **一度に触れてよい選択肢は2つまで**。協力者が知っているのも二択なので、それ以上要らない

選択肢の名前そのものは使える（使えないと何も伝えられない）。
20文字あれば名前は2つまでしか入らないので、名前だけで全部に触れることはできない。

## 5. まだ確かめられていないこと

- **人間の嘘つきは示し合わせるかもしれない。** AI助言者は互いを知らないので狙いがばらける。
  実測で、嘘つきが同じ外れに寄ると 82.9% → 76.2% に下がる
- **助言の言い回しから嘘を見抜けるか。** これが読みの本体だが、
  言葉の判断が絡むのでシミュレーションでは測れない
- 1部屋あたりの実時間。ボットは思考しないので、35〜40秒という前提は仮置き
