# 評価：今の形は成立していない

実際に遊び、実物のロジックで各30000部屋ぶん測った結果。再現は `tools/sim17.mjs` `tools/sim18.mjs` `tools/sim19.mjs`。

---

## 1. 一番痛い数字

同じ部屋・同じ助言を、複数の打ち手に同時に食わせて比べた。

| 打ち手 | 平均生存率 |
|---|---|
| 当てずっぽう | 19.1% |
| **名前が出た回数を数えるだけ** | **78.6%** |
| 断言を疑い迷いを信じる（設計どおり） | 79.2% |
| 記録で重みを変える | 79.7% |
| **嘘つきが誰か完全に知っている（上限）** | **78.7%** |

**嘘つきを全員知っていても、ただ数えるだけの打ち手に勝てない。**

腕の伸びしろは 78.6% → 79.7% の **1.1ポイント**しかない。
「名前が一番多く挙がったものを選ぶ」を覚えた時点で、そのプレイヤーの成長は終わる。

## 2. そもそも決断になっていない

| 区画 | 独走（2票差以上） | 僅差（1票差） | 同点 | 独走時の的中率 |
|---|---|---|---|---|
| 1 | **70%** | 20% | 10% | 98% |
| 2 | 56% | 29% | 16% | 96% |
| 3 | 41% | 36% | 22% | 92% |
| 4 | 44% | 34% | 22% | 88% |

区画1では**7割の部屋が「一目で分かる」**。しかも独走している選択肢は98%正解。
残りも、2割が同点＝コイン投げ。
考える価値のある部屋（僅差）は2〜3割しかない。

実プレイでもそのとおりの光景が出た。

```
潜っていいのはどれ？
  まめ    たぶん傾いた鳥居        こより  傾いた鳥居で間違いない
  みかん  傾いた鳥居か灯を吊った門  テツ    傾いた鳥居にしろ
  ぜんじ  灯を吊った門か傾いた鳥居  ゲンさん たぶん傾いた鳥居
  得点：傾いた鳥居=5.0 / 灯を吊った門=2.0 / 他=0
```

8人中6人が同じ名前を挙げている。決断ではなく確認作業。

## 3. 病名

**正解は必ず全協力者の手元にあり、協力者は嘘つきより多い。**
だから協力者の発言をどう集計しても正解に収束する。嘘つきが誰か分かっても関係ない。

これは一代目（全員が正解を知る→多数決で解ける）とまったく同じ病気で、
協力者を「二択まで」に留めても治らなかった。
**正解は全員の候補に入るのに対し、囮は各人ばらばら**なので、
数えれば正解だけが突出する。不確かにしたつもりが、集計を一段挟んだだけだった。

## 4. 前回の評価が間違っていた

前回「読みの差が16.5ポイント」と報告したが、あれは比較相手が悪い。
「断言を重く見る」＝**設計と逆の読み方**を基準にしていた。
そんな打ち方をする人はいない。

人が自然にやる「名前を数える」を基準にすると、差は **+0.6ポイント**しかない。
藁人形と比べて勝った気になっていた。

## 5. 直すなら

集計で解けてしまうのは、**助言が「どれか」を指しているから**。
指す限り、数えれば終わる。

助言を**属性についての言明**にすると、集計では解けなくなる。

- 選択肢に属性を持たせる（材質・色・状態・音・匂いなど）
- 協力者は正解そのものではなく「**正解は金属ではない**」のような真の制約を1つ知る
- 嘘つきは偽の制約を混ぜる
- 挑戦者は制約を重ね合わせて絞る

このとき、**誰も選択肢を名指ししない**ので数えようがない。
そして偽の制約が1つ混じるだけで結論がひっくり返るため、嘘つきが1人でも効く。

代償：部屋データに属性が要る（48部屋 × 5〜6択 × 属性）。
いまの「見た目で選ぶ」から「言葉で詰める」に寄るので、絵の役割が変わる。

**これは四度目の作り直しになるので、判断を仰いでから着手する。**

## 6. 面白い部分（残っているもの）

- **死亡演出**は効いている。0.8秒の無音から灯りが寄って死に文句が出る流れは、
  20部屋見ても飽きなかった
- **嘘つき役の体験**は面白い。正解を知りながら人を殺しにいく感覚は設計どおり
- **記録（正n 嘘n）**が画面に出るのは良い。実プレイで
  「はなこ（正0 嘘4）が傾いた鳥居は死ぬと言っている」という光景が生まれた。
  ただし上の数字のとおり、その気づきは勝敗に効かない

## 7. 他に見つかった問題

- **助言者の「耳打ち」役が薄い。** 「Xはやめろ」しか言えない。1周に何度も回ってくると作業になる
- **助言が出そろったか分からない。** 「N人が助言を送ってきた」とは出るが、
  発言枠の人数が出ないので、待つべきか決めるべきかの判断がつかない
- **絵が意味を持っていない。** 選択肢は実質テキスト。
  仮絵のままなので「見た目で判断する」余地がなく、配信で映える画にもなっていない
- **序盤で死ぬと何も見られない。** 実プレイの1周は7部屋で終わり、区画2に一度も入れなかった
