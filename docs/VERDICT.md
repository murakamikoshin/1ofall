## 1. 一番痛い数字

同じ部屋・同じ助言を、複数の打ち手に同時に食わせて比べた。

| 打ち手 | 平均生存率 |
|---|---|
| 当てずっぽう | 19.1% |
| **名前が出た回数を数えるだけ** | **78.6%** |
| 断言を疑い迷いを信じる（設計どおり） | 79.2% |
| 記録で重みを変える | 79.7% |
| **嘘つきが誰か完全に知っている（上限）** | **78.7%** |

**嘘つきを全員知っていても、ただ数えるだけの打ち手に勝てない。**

腕の伸びしろは 78.6% → 79.7% の **1.1ポイント**しかない。
「名前が一番多く挙がったものを選ぶ」を覚えた時点で、そのプレイヤーの成長は終わる。

## 3. 病名

**正解は必ず全協力者の手元にあり、協力者は嘘つきより多い。**
だから協力者の発言をどう集計しても正解に収束する。嘘つきが誰か分かっても関係ない。

これは一代目（全員が正解を知る→多数決で解ける）とまったく同じ病気で、
協力者を「二択まで」に留めても治らなかった。
**正解は全員の候補に入るのに対し、囮は各人ばらばら**なので、
数えれば正解だけが突出する。不確かにしたつもりが、集計を一段挟んだだけだった。

## 5. 直した（2026-09-09）

属性の制約案は**設計中に穴が見つかって却下**した。
「一番多くの制約を満たす選択肢を選ぶ」は結局また数える作業で、同じ病気になる。

代わりに原因そのものを潰した。**嘘つきの嘘が散っていたのが原因**だった。

- 正直者の声は1つ（正解）に集まる
- 嘘つきの嘘は外れの数だけ散る
- だから集計すると正解だけが突出する

そこで **嘘つき全員に同じ「罠」を見せた**。嘘が1点に集まるので、
罠が正解を票数で上回る部屋が生まれる。あわせて嘘つきを半数に増やし、
各自が毎回は嘘をつかない形にした（信用を作ってから裏切れる）。

| | 前 | 後 |
|---|---|---|
| 数えるだけ | 88.9% | **73.0%** |
| 記録を読む | 91.5% | **79.3%** |
| 腕の差 | +2.6pt | **+6.3pt** |
| **一番票が集まった選択肢の的中率** | **98%** | **85%** |

最後の行が要。**群れに従うと15%の確率で死ぬ。**
以前は一番票が集まった選択肢が98%正解で、7割の部屋が確認作業だった。

実ビルドでもそのとおりの光景が出た。

```
買っていいのはどれ？   正解＝客が触った品
  ゲンさん  隅に置かれた品か並んだ品のどっちか
  たろう   たぶん隅に置かれた品          ← 罠に4票
  イチ    隅に置かれた品で間違いない
  ゴロー   たぶん隅に置かれた品
  ノブ    安すぎる品か客が触った品のどっちか  ← 正解に3票
  ぬい    客が触った品な気がする
  せつ    客が触った品か並んだ品だ
```

### 実ビルドでの通しプレイ（直した後）

| | |
|---|---|
| 1周の選択回数 | 平均 14.8回 |
| 1部屋あたりの生存率 | **73%** |
| 同じ部屋の連続 | 0回 |

人間の思考時間を入れると1周 9〜11分。

なお、直す前に最適だった打ち方（断言を疑い、否定を引く）で遊ぶと
生存率が43%まで落ちる。**設計の変更が旧攻略法を無効にした。**

### 記録の付け方も直した

記録（正n 嘘n）を**隠れた役で付けていた**。これは二重に間違いだった。

- 挑戦者に見えないはずの配役をそのまま漏らしていた
- 「これは死ぬ」しか言えない耳打ち役は正解の名前を出さないので、
  正直なのに毎回「嘘」と記録されていた

いまは**振る舞い**で付ける。外れを避けろと言ったなら正しい、
正解を避けろと言ったなら嘘、押した先に正解が入っていれば正しい。

## 6. 当初考えていた直し方（却下）

集計で解けてしまうのは、**助言が「どれか」を指しているから**。
指す限り、数えれば終わる。

助言を**属性についての言明**にすると、集計では解けなくなる。

- 選択肢に属性を持たせる（材質・色・状態・音・匂いなど）
- 協力者は正解そのものではなく「**正解は金属ではない**」のような真の制約を1つ知る
- 嘘つきは偽の制約を混ぜる
- 挑戦者は制約を重ね合わせて絞る

このとき、**誰も選択肢を名指ししない**ので数えようがない。
そして偽の制約が1つ混じるだけで結論がひっくり返るため、嘘つきが1人でも効く。

代償：部屋データに属性が要る（48部屋 × 5〜6択 × 属性）。
いまの「見た目で選ぶ」から「言葉で詰める」に寄るので、絵の役割が変わる。

**却下。** 「一番多くの制約を満たす選択肢を選ぶ」＝最大の整合集合を探すことなので、
結局また数える作業になる。作り直す前に気づけた。
