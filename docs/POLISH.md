# 数字の外側を潰した記録

盤面のバランスは `docs/RUBRIC.md` の7項目でもう基準を満たしている
（通常 7/7・全員挑戦者 7/7・崖っぷち 6/7）。
そこから先、**「面白い」と言ってもらえない理由はバランス以外にある**
という前提で潰したものを、症状ごとに並べる。

再現に使う道具は `tools/` に置いてある。どれも実物のビルドを
本物のブラウザで動かして測る。

| 道具 | 見ているもの |
|---|---|
| `tools/stress.mjs` | 900周×3モード×2言語の総当たり。進行が止まらないか |
| `tools/brief-check.mjs` | 手引きの出方、持ち時間が止まるか |
| `tools/a11y-check.mjs` | 挑戦者画面。はみ出し・文字切れ・的の大きさ・Tab移動 |
| `tools/a11y-advisor.mjs` | 助言者画面。320px幅まで |
| `tools/advisor-roles.mjs` | 5つの立場×2言語の画面 |
| `tools/title-fit.mjs` | 表題が画面に収まるか |

---

## 1. 進行が止まる（致命）

総当たりで **5170部屋中2部屋**、全員挑戦者モードで
**同じ部屋の全員が同時に脱落すると発言者が0人になり、進行が止まった**。
確率にすると0.04%だが、当たった配信はそこで終わる。

最低3人は呼び戻すようにした（`GameEngine.applyResting`）。

## 2. 規則を誰も教えていなかった

一部屋目に入るまでに分かることが何もなかった。特に効くのは二つ。

- 嘘つきが誰かは**区画のあいだ変わらない**（だから記録が意味を持つ）
- **名の挙がった数が多い道が正しいとは限らない**（嘘つきは全員同じ罠へ誘う）

これを知らずに入ると初回はほぼ死ぬ。全員挑戦者モードに至っては
「自分に見えている手がかりは自分にしか見えていない」という
前提そのものが伝わっていなかった。

モードごとに初回だけ手引きを挟み、表題からはいつでも読めるようにした。
対局中は HUD の「?」から開く。**開いているあいだ締切を後ろへずらす**ので、
読んでも損をしない（助言は読んでいるあいだも届く）。

## 3. 部屋が足りない

1周は最大32部屋。48部屋しかなく、2周目の3分の2が再訪だった。
79部屋に増やした（新規50案のうち、問いが重複する19案は見送り）。
追加後もルーブリックの数字は動いていない。

## 4. 触れる的が小さい

助言の行の「黙らせる」「通報」が20〜23pxしかなかった。
指では押し間違える大きさで、しかも**間違って押して痛いのがこの二つ**。
28px（指なら32px）を下限にした。通報ボタンには CSS が一行も
当たっておらず、素のボタンのまま出ていた。

表題は項目が増えて 1366x768 で「一人で遊ぶ」が画面外に出ていた。
縦が詰まる端末用の詰め方を足した。

## 5. 裏切り者に、裏切り者だと伝わっていない

助言者ページが `knowledge.kind === 'liar'` だけを嘘つき扱いしていた。
全員挑戦者モードの裏切り者は `'trapper'`（正解は知らないが罠は知る）
なので、**本人の画面には「あなたは助言者だ」と出て、罠も光らなかった**。
人間が助言者席に座る段になったらそのまま出ていた。

あわせて、扉が光っているのに「どれかは分からない」と出ていた文言を
「生きる方は光った2つのどれか。それ以上は分からない」に変えた。

## 6. 死んでも何も残らない

1周が10分を超えるのに、死んだら数字がひとつ出て消えるだけだった。
到達部屋数をモードごとに覚えて、終わりの画面と表題に出す。
順位表でも実績でもなく、**次に越える線が一本あるかどうか**の話。
