# 「面白いか」の基準と、いまの数字

実際の10人には聞けないので、**これまでの検証で「面白くない」と分かった症状を裏返して基準にした**。
`node tools/rubric.mjs` で再現できる。

> **32回目より前の数字は、物差しのほうが間違っている。**
> 本体にある規則を物差し側に写していた箇所が三つ食い違っていた
> （読み替え・名指しの正誤・配役。下の「崖っぷちモード」の節に一覧）。
> 崖っぷちが一番大きく動いた（生存率 68.9% → 77.1%、腕の差 17.9 → 30.7pt）。
> 通常も動いた（74.7% → 76.8%、12.7 → 15.4pt）。
> このページの古い節に残っている数字は**記録としてそのまま残す**。
> 直したあとの値は各モードの節の表にある。

| 項目 | 狙い | なぜ |
|---|---|---|
| 決断率 | 50%以上 | 一目で決まる部屋ばかりだと確認作業になる。以前は7割が一目で決まった。**票が集中していても集中先が罠なら「決まった」とは数えない**（従うと死ぬので。むしろ一番面白い部屋） |
| 群れの罠率 | 10%以上 | 票が集まった選択肢が必ず正解だと、群れに従うだけの作業になる |
| 腕の差 | 8pt以上 | 素朴な打ち手と読める打ち手の差。以前は0.6ptしかなかった |
| 生存率 | 72〜85% | 低いと理不尽、高いと緊張が消える |
| 1周の長さ | 10〜15分 | 配信向けゲームの相場から。以前は18秒だった |
| 短命率 | 15%未満 | 5部屋以下で終わる周が多いと、何も見られずに終わる |
| 最良差 | 6pt以内 | 最良の打ち手が一つに固まると攻略が終わる |

打ち手は同じ部屋・同じ助言に食わせて比べる（当てずっぽう／自分の情報だけ／数えるだけ／
記録で重み付け／迷いを信じ記録も見る／一番信用できる一人に賭ける／
撃たれた者を信じる／撃たれた者を疑う／票が集まりすぎたものを避ける）。
「黙らせる」も含めて1周を通しで回す。

### 決断率の数え方を一度変えている

「票が集中している部屋」を全部「一目で決まる部屋」に数えていた。
嘘つきが区画の後半でまとめて裏切るようにしたら、
**集中先が罠である部屋が増えて、この数字が下がった**（崖っぷち 50.0%→46.5%）。
罠に票が集中している部屋は、従うと死ぬので決まっていない。
数え方を「集中していて、かつ集中先が正解」に直した。
生の集中率は参考として別に出す（崖っぷち 53.5%、そのうち 42.5% が罠）。

### 常連の裏切り歴は、**奥で効いて頭では損をする**

27回目に顔ぶれを固定して「裏切2/5」を出した。区画の一部屋目は記録が白紙なので、
そこだけは唯一残る手掛かりになる——はずだった。96種で測ると逆だった。

| 部屋 | 読める | 常連の癖も見る | 差 |
|---|---|---|---|
| 1 | 74.2% | 69.5% | **−4.7pt** |
| 2 | 72.1% | 71.4% | −0.7pt |
| 3 | 68.5% | 70.1% | +1.6pt |
| 4 | 76.8% | 71.9% | −4.9pt |
| 5 | 70.6% | **75.5%** | +4.9pt |

理由は二つ重なっている。**嘘つきは区画の前半で本当のことを言う**（裏切りの段取り）。
そして `liarBias` が高い者は、嘘つきに引かれやすい一方で**嘘つき回でも正直寄り**
（`liarHonestyRate = liarHonesty × liarBias`）。
つまり「よく裏切る常連」を頭から薄く聞くと、**一番正直に喋っている人を薄く聞く**。

札の正しい読み方は「序盤は真に受けない、奥で効かせる」になる。
崖っぷちでは全区間で損をする（ほぼ全員が嘘つきなので、癖で薄く聞くと
一人しかいない正直者を薄く聞く）。`tools/arc-probe.mjs` で出る。

## 全員挑戦者モード：7 / 7（三つで最良）

全員が同じ部屋を歩く。仲間も選び、死ぬ。挑戦者自身にも部分情報（三択）が配られる。
嘘つきは**どれが死ぬかだけ知っていて、正解は知らない**。

| 打ち手 | 1部屋生存 |
|---|---|
| 当てずっぽう | 20.1% |
| 自分の情報だけ | 42.7% |
| 数えるだけ | 40.2% |
| **設計どおり** | **82.6%** |

> **32回目の直し。** ここまでの全員挑戦者の数字は、`party-sim` が
> `aiCalls()` を呼んでいなかったので**撃ち合いの一列が無い遊び**を測っていた。
> 同じ抜けが `local-party.ts`（手元で遊ぶほう）にもあり、
> 部屋で遊ぶときだけ撃ち合いが起きていた。両方入れて、
> AI の読み方の向きも実測（`tools/shot-probe.mjs`）に合わせて
> 「撃たれた者を疑う」に直した。上の表と下の項目は直したあとの値。
>
> ```
>                               1部屋生存  最後まで  踏破  腕の差  運任せ
> 撃ち合い無し（31回目まで）        81.9%    46.8%  76.0%  39.5pt   8.2%
> 撃ち合いあり・撃たれた者を信じる    79.9%    37.6%  65.2%  40.8pt   5.8%
> 撃ち合いあり・撃たれた者を疑う     82.6%    49.6%  80.8%  42.5pt   5.6%
> ```

| 項目 | 値 | |
|---|---|---|
| 決断率 | **79.4%** | ○ |
| 群れの罠率 | **43.9%** | ○ |
| 腕の差 | **31.1pt** | ○ |
| 生存率 | 82.0% | ○ |
| 1周 | 14.1分 | ○ |
| 短命率 | 0.6% | ○ |
| 最良差 | 4.2pt | ○ |

**数えるだけが40.2%まで落ちる**（腕の差 42.5pt）。ずっと戦ってきた
「集計で解ける」病に、この形が一番強い。

理由は三つ。

1. **他人の話の価値が +40pt。** 自分の情報だけなら42.7%、他人も読むと82.6%
2. **嘘つきにも命が懸かる。** 助言者モードでは嘘をつくコストがゼロだった
3. **同時に選んで結果が開くので、言ったことと選んだことのずれが見える。**
   「隅の袋で間違いない」と言った者が手前の椀を選んでいたら、それが証拠になる

### 二つの壊れ方を潰してある

**嘘つきが正解を知ると、一度も死なないので8部屋で丸わかりになる**
（死亡回数 正直者2.16回 / 嘘つき0.00回）。
罠だけを知る形にすると 2.16回 / 2.04回 で見分けがつかなくなる。生存率は変わらない。

**死んだ仲間は次の部屋を休む。** これが無いと、嘘つきが「自分も罠に落ちて見せる」
camouflage を無料で使える。休むぶん声を失うので、賭けになる。

### 32回目：この物差しは長いあいだ別の遊びを測っていた

三つ食い違っていた。どれも**本体にある規則を物差し側に写していた**ことが原因で、
どれも崖っぷちを実際より読みにくい側に寄せていた。

```
1. 「信用を作っている最中の裏切り者は仲間と同じ側に立つ」を写していなかった
     → 撃ち合いから読める量が実際より多く出ていた
2. 名指しの正誤を記録に積んでいなかった
     → 本体では外した名指しは傷として残る。記録で読む打ち手が実際より弱く出ていた
3. **配役の写し違い。** 「正直者はただ一人」を
     speakerIds.filter((_, i) => i !== Math.floor(rng() * len))
   と書いていた。filter の中で毎要素 rng() を引くので、正直者の人数が
   0人32% / 1人42% / 2人21% / 3人以上5% になっていた。
   **3回に1回は正直者のいない区画**（読んでも当たらない）を測っていた
```

三つ直した結果。

```
崖っぷち（rubric）      生存率   腕の差
写し違いのまま           68.9%   17.9pt
1と2を直す             69.3%   19.1pt
3も直す（正しい配役）     78.3%   30.2pt   ← 尺が16.4分で枠割れ
区画を5部屋にする        77.1%   30.7pt   7/7
```

区画を6部屋から5部屋にしたのは、生存が上がったぶん奥まで行くようになって
1周が16.4分（枠は10〜15分）になったから。**このモードの説明にはもともと
「5部屋ごとに顔ぶれを入れ替える」と書いてあって、コードだけ6だった。**

道具（黙らせる）を使ったエンジン側の数字（`tools/brink-probe.mjs`）は
1部屋あたり生存 71.2%（枠 65〜82%）、踏破 19.5%。

このモードでは **撃たれた者を信じる** が効く（通常では逆向きになる）。
嘘つきが多数なので、群れが撃つのは真実を言った一人しかいない。
ただし**区画の序盤は逆を向く**（`tools/shot-probe.mjs`）。

```
撃たれた者が正解を口にしていた割合 − 撃たれていない者
              1部屋目    2      3      4      5
通常          -33.9pt  -24.3  -16.8  -12.6   -9.6
崖っぷち       -8.8pt   +4.7  +18.2  +23.7  +30.0
全員挑戦者    -35.7pt  -36.8  -38.3  -39.6  -42.5
```

区画の中の読みしろ（`tools/arc-probe.mjs`、400種）。

| 部屋 | 読める | 数えるだけ | 読みしろ |
|---|---|---|---|
| 1 | 39.7% | 58.8% | **−19.1pt** |
| 3 | 61.9% | 45.3% | +16.6pt |
| 5 | 71.9% | 37.3% | **+34.7pt** |

**区画の一部屋目だけは、読むと損をする。** 記録が白紙で、撃ち合いの向きも
まだ逆を向いているため。手引きに向きを書いたが、一部屋目に何を読ませるかは
まだ形が無い。

## 設計を作り直した経緯

1. 全員が正解を知る → 多数決で解ける（全構成で生存率100%）
2. 助言を伏せて数通だけひらく → 運ゲー（ひらく時点で判断材料が無い）
3. 協力者に正解を教えない → まだ数えるだけで解けた（腕の差0.6pt）
4. 嘘つき全員に同じ罠を見せる → 嘘が1点に集まり、群れが罠になる
5. 嘘つきを半数にし、毎回は嘘をつかせない → 記録が効くようになる
6. 嘘つきが迷ったふりもできるようにする → 「断言＝嘘つき」を機械的でなくする
7. 黙らせるを評価に含める → 上手い人だけが使える道具として腕の差が開いた

### 途中で捨てた案

- **属性の制約**：「一番多くの制約を満たす選択肢を選ぶ」＝最大の整合集合を探すことなので、
  結局また数える作業になる。部屋データに属性を付ける前に気づけた
- **嘘つきの人数を区画ごとに振る**：変動が区画単位でしか起きず、
  嘘つき1人の区画は6部屋まるごと確認作業になった
- **何も知らない助言者を混ぜる**：半分入れると生存率が61%まで落ち、
  落ちたぶんがそのまま運になった

## 言語ごとの検証（2026-09-09 追加）

基準はすべて日本語で測っていた。英語で測ったら**壊れていた。**

- 助言の言い回しが日本語で直書きされていて、英語では
  「New straw sandalだ」「たぶんMuddy clog」になっていた
- 真偽の判定（記録の正誤）が日本語の言い回し専用で、英語では素通り
- 番号と位置の禁止も日本語専用。英語の `second` `left` `middle` が通っていた
  ＝「1234は罠」の抜け道が英語で開いていた
- 文字数上限20文字は日本語向けの値。英語のラベルは長いので枠が足りなかった（42文字に）

直した後、英語でも同じ数字になる。

| | 日本語 | 英語 |
|---|---|---|
| 全員挑戦者 | 7/7（腕の差31.1pt） | **7/7（腕の差32.0pt）** |
| 崖っぷち | 6/7 | 6/7（同じ1項目） |

`npm run test` に言語ごとの見張りを入れた。
他言語の混入・文字数超え・空の助言・言い回しの偏り・真偽判定・番号禁止を全言語で確認する。
このテストを書いた直後に、英語の真偽判定がもう一件壊れているのを捕まえた
（冠詞を直したときに判定パターンを合わせ忘れていた）。

## この基準の限界

**実際の人間に聞いていない。** ここで測っているのは
「機械的な攻略に対してどれだけ抵抗があるか」であって、面白さそのものではない。

そして測定の相手は**AI助言者が定型文で喋る条件**で、これは機械的な攻略が最も効く状況。
人間が20文字を自由に書く本番では、言い回しの解釈という機械化できない層が乗る。
そこは通信層を繋いでからでないと確かめられない。

### 言い回しを増やしても数字は動かなかった（20回目の追記）

「二つに絞れている」型の言い方を4→14種に増やした（`docs/PLAYLOG.md` 20回目）。
迷いを含む言い方と含まない言い方の比を10:4に保ったので、
測り直しても揺れの幅（1部屋・標準誤差 ±1.6pt）の中にある。

| | 前 | 後 |
|---|---|---|
| 通常 腕の差 | 12.7pt | 12.7pt |
| 通常 生存率 | 74.7% | 74.7% |
| 崖っぷち 腕の差 | 22.1pt | 21.9pt |
| 崖っぷち 生存率 | 73.2% | 72.9% |

このページの数字は後のほうに揃えてある。

### 7項目に入っていないもの（16回目の追記）

**手応えが返る回数**を、この7項目は数えていない。

16回目まで、「誰が嘘つきだったか」は命が尽きたときにしか返らなかった。
1周12分・区画四つの遊びで、読み合いの答えが最後に一度だけ返る形である。
7項目は全部通っていた——腕の差も、生存率も、攻略の固定化も。
**それでも、読んだことが当たっていたかが12分間わからない。**

区画を離れるときに答え合わせを挟んだ。均衡の数字は一つも動いていない
（配役の作り方も部屋数も触っていないので、動くはずがない）。
基準の側に足せていないが、ここは「数字が全部通っていても面白くない」
穴の一つとして残す。
